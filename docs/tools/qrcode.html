QR code generator

Turn a URL or any text into a QR code and download it as PNG or SVG, directly in your browser

Paste a URL or some text: the QR code updates as you type, can carry a logo in its centre, and can be downloaded as a PNG image or as a scalable SVG. Everything happens in your browser, nothing is sent to a server.

About

  • Private: the QR code is computed entirely in your browser. Nothing you type is sent to a server or stored.
  • Static and permanent: the content is encoded directly in the image. The code does not go through any redirect service, never expires, and keeps working even if this page disappears, as long as the encoded URL itself stays online.
  • Formats: SVG is a vector image that scales to any size without blurring, making it ideal for posters and print; PNG works everywhere (slides, documents, messages).
  • Error correction: higher levels make the code more robust to damage, dirt or a logo placed on top, at the cost of a denser code. Medium is a good default; use High if you plan to cover part of it.
  • Logo: the image stays on your computer (it is never uploaded) and is embedded in the downloaded files. It hides part of the code, which scanners rebuild thanks to error correction, so High is selected automatically and the page checks that the code still decodes. Keep the logo small and always test-scan with a phone before printing.
  • Scanning tips: keep dark modules on a light background, with good contrast and a margin of about 4 modules around the code.

QR codes are generated with qrcode-generator by Kazuhiko Arase (MIT licence), and checked with jsQR (Apache 2.0 licence). “QR Code” is a registered trademark of DENSO WAVE INCORPORATED.
